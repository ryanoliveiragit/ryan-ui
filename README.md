# ryan-ui

React components and blocks with motion, built with CSS modules and design tokens.

- **Site:** https://ryanoliveiragit.github.io/ryan-ui/
- **Library:** 179 components and 42 blocks, each with a live demo, guide and API reference.
- **Source:** the site's source code is in [`source/`](source/).

## Install a free item

```bash
npx shadcn@latest add https://ryanoliveiragit.github.io/ryan-ui/r/button.json
```
