# OTP input

## Installation

With the shadcn CLI (one command copies the code and installs the dependencies):

```bash
npx shadcn@latest add https://ryanoliveiragit.github.io/ryan-ui/r/otp-input.json
```

With another package manager: `pnpm dlx shadcn@latest add https://ryanoliveiragit.github.io/ryan-ui/r/otp-input.json`, `yarn dlx shadcn@latest add https://ryanoliveiragit.github.io/ryan-ui/r/otp-input.json` or `bunx --bun shadcn@latest add https://ryanoliveiragit.github.io/ryan-ui/r/otp-input.json`. Registry path, relative to the site address: `r/otp-input.json`.

- npm packages: `motion`
- Files, once installed:
  - `components/ryan-ui/otp-input/otp-input.tsx`
  - `components/ryan-ui/otp-input/otp-input.module.css`

First time in the project: install the foundation once (`npx shadcn@latest add https://ryanoliveiragit.github.io/ryan-ui/r/ryan-foundation.json`) and import `@/components/ryan-ui/foundation.css` at the root of the app. Requires React 19 and the `@/` alias.

### Manual

1. Install the packages: `npm install motion`.
2. Copy the files listed above. The content of each one is in `r/otp-input.json` (field `files[].content`).
3. Make sure `foundation.css` (the tokens) and `motion-tokens.ts` are already in your project.

## When to use

- Fixed-length verification code, sent by email or SMS or generated by an authenticator app, typed cell by cell.
- When pasting the whole code needs to work: the pasted text is distributed across the cells starting from the focused one.

## When not to use

- Use [`sign-in`](sign-in.md) when you want the whole email-and-code flow already assembled, with resend and account state.
- Use [`input`](input.md) for variable-length codes or codes with separators, such as coupons and recovery keys.
- Use [`password-field`](password-field.md) for secrets that should not appear on screen; here the characters are visible.

## Usage

The demo from the item page, with imports as they look after installing through the CLI. `Stack`, `Row`, `Caption`, `Field` and `Surface` (from `./_kit`) are site layout helpers: replace them with your own project layout.

```tsx
import { useState } from "react";
import { OtpInput } from "@/components/ryan-ui/otp-input/otp-input";
import { Caption, Stack } from "./_kit";
import type { DemoStage } from "./_kit";

export const stage: DemoStage = { layout: "center", height: 360 };

export default function OtpInputDemo() {
  const [code, setCode] = useState("");
  const done = code.length === 6;
  const wrong = done && code !== "482913";
  return (
    <Stack width={380} gap={3} align="center" style={{ textAlign: "center" }}>
      <OtpInput
        label="Verification code"
        description="Enter the 6-digit code we sent to maya@northwind.studio."
        value={code}
        onChange={setCode}
        error={wrong ? "That code is not right. Try 482913." : undefined}
      />
      <Caption>{done ? (wrong ? "Rejected" : "Verified") : `${code.length} of 6 digits. Paste works too.`}</Caption>
    </Stack>
  );
}
```

## Keyboard

| Keys | Action |
| --- | --- |
| `←` or `→` | Move focus to the previous or next cell. |
| `Backspace` | In an empty cell, clears the previous cell and moves focus to it. |
| `Delete` | Clears the character in the focused cell. |
| `Ctrl + V` | Pastes the code starting from the focused cell; in numeric mode, anything that is not a digit is discarded. |
| `Tab` or `Shift + Tab` | Go through each cell: all of them are independent fields in the focus order. |

## Accessibility

- The cells form a `role="group"` with an `aria-label` coming from `label`, and each field identifies itself as “digit N of M”, in English hardcoded in the file.
- `description` and `error` are linked to all cells by `aria-describedby`; with an error, the cells receive `aria-invalid` and the message is a `role="alert"`.
- The first cell uses `autoComplete="one-time-code"`; in forced colors the animated ring disappears and the native focus outline returns.

## Motion

- Each digit rises into the cell from a slight blur; when pasting, the digits arrive in a wave from left to right.
- A single focus ring slides between cells with a short spring, and a new error shakes the row sideways once, with the message opening its own height.
- With “reduce motion” on, digits only fade, the ring jumps between cells, there is no shake, and messages appear without animation.

## Responsive behavior

- The cells are 42 × 48 px and shrink in width when the row does not fit; up to 360 px of viewport the gap between them drops to 6 px and the height to 44 px.

## Notes for AI

- It is controlled only: without `value` and `onChange` the typed digits do not appear; `onChange` returns the compact string, so check `value.length === length` to validate or submit.
- `label` is required; `length` is 6 by default, `inputMode="text"` accepts letters, and passing a new `error` triggers the shake.
- Import from `@/components/ryan-ui/otp-input/otp-input` (it does not live in `blocks/`); there is no `onComplete`, and `sign-in` and `login-centered` show how to submit when the last cell is completed.
